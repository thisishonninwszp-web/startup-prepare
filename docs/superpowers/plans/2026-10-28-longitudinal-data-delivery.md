### 固定统计分母

从官方元数据中为表章、行业、雇用规模、经营组织、地域、统计时点逐项选择一个代码，先预览原值、单位与覆盖，再确认批准固定来源版本。服务器在批准时重取元数据和单格结果，对不上预览就拒绝。已提交但响应丢失的批准/刷新请求优先检查本地回执，不依赖官方接口继续可用；相同请求ID换筛选仍拒绝。

当前仅接入e-Stat固定表 `0004006264`，不扩展为任意统计表搜索，不加总父子分类。原始回应、分类标签、筛选、统计时点、元数据哈希及修订保留；源口径改变后需重新预览和批准。相同统计单元的差额标作来源修订，不能解读为实时增长。零、秘匿、缺失、失败分开。

**实机分母案例：** 2021年经济普查，`tab=201-2021`（企業等数）、`cat01=751`（旅館，ホテル）、`cat02=00`、`cat03=0`、`area=00000`（全国）、`time=2021000000`，返回 **26,899 企業等**。这是该表分类下的企业等数，不是门店/事业所数、2026年存量、目标客户或支付意愿。metadata更新日为2026-09-30。官方接口只读核验及脱敏回应保存在 `lib/domains/observations/statistics/fixtures/`，PARAMETER/APP_ID没有保留。

依据：[官方统计表](https://www.e-stat.go.jp/dbview?sid=0004006264)、[e-Stat API 3.0官方说明](https://www.e-stat.go.jp/api/api-info/e-stat-manual3-0)。仅使用项目既有ESTAT_APP_ID，未输出凭证或使用演示令牌。固定host、拒绝重定向、超时和响应大小限制均已实现。

可明确关联本人想法，保存适用范围与未知，不创建validation或改变想法状态。删除来源会清理快照和私人关联内容并显示删除占位。手工输入不能冒充在线批准来源；本期没有新的手工统计导入界面。

### 告知后才启用的原型事件

先保存停用定义：实际HTTPS原型地址、告知地址/版本、事件白名单及1至30天保留期。再明确确认原型和告知已实际存在，才能激活并获得仅显示一次的服务端令牌。未确认真实原型时不激活、不生成访客采集记录。本次没有创建任何真实接入项目。

仅接收以下事件及严格属性，不接收原始查询文本、姓名、邮箱、IP、设备指纹或任意JSON：

| 事件 | 允许属性 |
| --- | --- |
| query | resultCount |
| no_result | 空对象 |
| task_completed | durationBucket枚举 |
| return_visit | interval枚举 |
| inquiry | channel枚举，不收实际邮箱 |
| payment | amountMinor、currency、one_time/recurring枚举 |

外部UUID、发生时间和告知版本必须提供；可选匿名标识只接受64位单向散列。发生时间与收录时间分开。入口为服务端 `POST /api/product-events`，Bearer令牌不得放入网页或访客浏览器。接口限体积、按源限速并去重，owner从令牌派生；撤销、轮换、停用、错误告知版本均阻止后续接入。

令牌只在服务器保存hash，浏览器仅内存显示，不放表单、日志或sessionStorage。令牌操作已提交但响应丢失时，重试只确认已处理，不能再次恢复明文；需要重新轮换。详情及属性示例见 `lib/domains/observations/product-events/README.md`。

用户可将事件明确关联本人想法，保存范围与未知。点击、咨询或单次付款不变成has_pain/will_pay，也不代表长期需求成立。删除后事件属性/匿名标识/外部ID和关联说明清除，引用只显示占位。保留期按收录时钟执行，读取时和清理入口分批清除过期内容；超过单批的过期原文/关联也会立即隐藏为不可读或占位，不能从备用副本取回。物理清理需要重复运行至完成，未声称默认已有后台清理任务。

### 经批准来源的预算调度

只接受116当前批准的固定e-Stat配置。选择周期（至少60分钟）、东京自然日的整数请求预算、连续失败上限；新建默认停用。每轮先预留两次HTTP额度，每次网络请求前重新检查授权、配置、租约并记请求；正常结束退还未尝试额度，过期worker保守保留两次扣额。预算是请求次数，不是想法分数或对其他收费服务的费用估计。

租约与版本保护防止重复worker重复保存/计账。结果保存与116统计快照写入同一事务；停用、配置失效、来源删除、跨日租约、过期worker都不能保存已在途结果。连续失败指数退避且有上限，健康状态与原因可见；失败不会显示为零需求。首次完成响应丢失后的重试按数据库已冻结终态汇总，不误报为另一种结果。

本期仅固定e-Stat适配器可执行，没有后台启动旧RSS/AI或其他付费来源。源口径变更后旧调度阻止运行，需要用户重新批准/绑定新来源。没有增加生产timer配置；保存enabled配置也不代表后台定时器已经调用。
