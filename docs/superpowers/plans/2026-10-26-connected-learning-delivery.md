# 决策联动首批交付：P1 / P1A / P2

2026-10-26，本地实现完成，尚未执行远端迁移、推送或部署。沿用 `codex/event-dossiers-phase-a`，保留之前未提交的事件档案依赖和用户已有配置修改。

## 可以走通的流程

1. 从想法或信息缺口建立人工观察任务，保存问题、希望改变的决定、地区/语言/时间、固定/探索词组及种子由来；修改配置产生新版本。
2. 保存带来源与时间范围的人工记录，区分失败、不可用、零、缺失和低量抑制；运行和原文快照不可覆盖。
3. 导入支持格式的Google Trends时间序列CSV或关键词规划CSV/TSV，先预览、再确认。支持UTF-8与带BOM的UTF-16，异常行阻止确认，保存原始导出并明确未经在线核验。
4. 用户明确将导出标签对应到任务词组，保留原标签、对应关系及固定/探索/未分配状态。AI种子与实际导出观测分开显示；研究用途包含问题、办法、替代与购买表述。
5. 对两次已保存导出核对口径。来源、地区、语言、时间范围、日期、词组、导出分类等元数据不同则不直接比较；不把搜索量解释为人数、付费意愿或市场规模。
6. 根据当下资源建立公开前提核对、任务重建、手动原型测试、公开试用计划或待接触问题。没有资源时保留约束，不强迫编造接触。
7. 保存实验判据、限制、预算及样本，运行开始时冻结样本清单和判据。逐案记录结果、上下文、人工补救和工件，完成必须原子提交全部冻结样本。
8. 追加结果引用到原信息缺口，由用户判断是否回答了原问题。重新生成缺口不能删除已关联的问题；纠错保留旧版本和旧运行，可引用被替代运行。
9. 工作台显示待接触问题与对应想法入口；时间线将原型/资料核对区别于真实接触。
10. 从成功的搜索导入准备接触画布，带入问题、可修改提纲和来源运行。创建时再次核对owner、冻结配置与口径；只保存私人画布，不发送消息、不调用AI。其他人工运行提供普通接触入口，不伪装已自动带入资料。

## 验证边界

- 首版观察任务只绑定想法，工作台其他对象保持既有行为；没有宣称所有对象已支持主动采集。
- 本期不接Google Ads/Trends实时API，不配置自动抓取、调度、广告或公开发布。支持明确的导入列格式，不保证所有语言/版本的导出均可识别。
- 实验域不输出需求yes/no；真实接触信号仍在既有validations记录。合成输入、AI模拟或自测通过不能变成客户认可。
- 新保存路径不写validations、不改想法状态、不刷新last_activity_at。对新增实验/观察引用，即使用户把缺口标got，也不将这些引用视为真实活动；旧普通证据的既有规则保留，没有新增或重写锁定政策。
- 归属已知的合成/AI观察不能改称公开材料；引用观察或材料时核对实际记录、原文、URL与owner。用户自行导入的材料不冒充系统从网站核实过的数据。
- 原有补证据入口在109缺失时仍可保存普通记录；新引用必须专用RPC，不能伪造。只有迁移后提供原子追加保证，旧路径回退保留原有并发局限。
- 运行历史在按页读取的20份实验版本范围内完整读取子记录，避免遗漏冻结样本；单版本最多200样本。长期大量运行的独立历史分页仍可继续优化。

## 数据库与开关

新增迁移顺序：

1. `supabase/migrations/108_decision_observations.sql`：观察任务、配置版本、运行快照、引用和权限。
2. `supabase/migrations/109_idea_experiments.sql`：实验版本、样本、冻结运行、结果、原子缺口引用和权限。

新模块不依赖105–107内部表；此前事件档案的发布闭环仍独立待完成。迁移108/109按顺序执行，不能把非幂等创建脚本反复执行。

两个开关默认关闭：`DECISION_OBSERVATIONS_ENABLED=true`、`IDEA_EXPERIMENTS_ENABLED=true`。先迁移再检查，再在测试环境开启；缺迁移时原有想法、捕捉、工作台和真实验证仍可使用。

远端结构检查：

```powershell
npm run db:check -- --connected
```

它探测8张新表和9个RPC，null owner必须在任何写入前被拒绝。该命令不执行迁移或创建业务记录。
