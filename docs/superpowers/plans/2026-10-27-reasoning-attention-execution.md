# P5 来源纠错、解释质量与注意力管理实施计划

> **For agentic workers:** 使用 subagent-driven-development 分工推理后端、注意力后端和嵌入UI；root负责上下文来源选择、页面挂载、集成验证与交付。沿用当前有未提交依赖的功能分支，不提交、部署或执行远端迁移。设计范围来自用户已批准并要求继续执行的路线图P5，不重新征求同一范围授权。

**Goal:** 在用户主动选取的事件材料上检查信息增量、比较口径与解释链，保留来源更正的影响，并用可退出的阅读约定和事前固定规则回看自己的取舍。

**Architecture:** 复用105/106不可变来源快照与研究记录；新增114推理日志/纠错影响、115阅读约定/材料登记/固定留样/自愿盲标题实验。全部owner隔离、服务端校验、追加历史和幂等。无新AI调用、外部采集、验证/想法状态/接触计时副作用。默认开关关闭。先提供手动引用和人工核对，不自动判真伪或静默跳过报道。

**Tech Stack:** Next14 App Router、TypeScript、Supabase、Tailwind/shadcn，现有ConnectedForm、request digest、Vitest、PGlite和本地Chrome夹具。
