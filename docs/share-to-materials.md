# 从手机分享进材料箱

在手机上看到一篇文章、一段话，点「分享」就存进 IdeaOS 的材料箱：
网页会去读正文（读不到就只存网址并说明为什么），然后照常走 AI 起草和审阅。
分享时可以顺手写一句「为什么存这个」，会放在材料最前面。

## 先在 Vercel 加两个环境变量（一次）

| 变量 | 填什么 |
|---|---|
| `SHARE_TOKEN` | 一串够长的随机字符（至少 16 位），相当于口令。用下面的命令生成一个 |
| `SHARE_USER_EMAIL` | 你登录 IdeaOS 用的邮箱 |

```bash
node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"
```

加完重新部署一次。两个都没配的话接口是关着的。口令泄露了就换一个新的，快捷指令里也跟着换。

## iPhone：做一个快捷指令（一次，五分钟）

1. 打开「快捷指令」App，右上角 **+** 新建。
2. 点最上面的名字，改成「存进 IdeaOS」。点底部的 **ⓘ**，打开 **在共享表单中显示**，
   接收的类型只留 **URL** 和 **文本**。
3. 添加操作 **询问输入**：提示写「为什么存这个？（可以空着）」，类型选「文本」。
4. 添加操作 **获取 URL 的内容**（Get Contents of URL），展开后：
   - URL：`https://你的域名/api/share`
   - 方法：**POST**
   - 头部：加一个，键 `Authorization`，值 `Bearer 你的口令`（Bearer 后面有一个空格）
   - 请求体：**JSON**，加两个字段：
     - `text`（文本）＝ 选变量「快捷指令输入」
     - `note`（文本）＝ 选变量「询问的输入」
5. 添加操作 **获取词典值**：键填 `message`，词典选上一步的「URL 的内容」。
6. 添加操作 **显示通知**：内容选「词典值」。

之后在 Safari、微信、X、Yahoo 新闻里点「分享」→ 往下找「存进 IdeaOS」。
几秒后会弹通知：「存进材料箱了：文章标题」，或者「存了网址，但没读到正文」。

微信里的文章：右上角 **…** → 「在 Safari 中打开」再分享；或者「复制链接」后在快捷指令 App 里运行一次（把链接粘进去）。

## Android：装成 App 就能分享

用 Chrome 打开 IdeaOS → 菜单「添加到主屏幕」。之后分享菜单里就有 IdeaOS：
分享网址会打开材料箱、网址已经填好，点一下存；分享一段文字会打开捕捉框。

## 读不到正文的情况

要登录才能看的页面、正文是脚本画出来的页面（一部分 SNS）、图片和 PDF 读不到。
这时材料里只有网址，打开那条材料把正文贴进去就行。
服务器只去读公网上的网页，localhost、局域网、云服务器的内部地址一律不去（`app/(app)/materials/fetch-page.ts`）。
